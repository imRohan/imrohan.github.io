There are several ways to automate torrents on your personal computer. For this example ill be using a Mac environment, however I am sure that there are equivalent programs for Windows. There are a few steps required for a torrent to begin downloading, mainly downloading the torrent file from a reputable torrent tracker. A tracker is responsible for allowing “peers” to communicate with each other using the BitTorrent protocol. A few examples of popular trackers are (in no specific order) The Pirate Bay, Kick Ass Torrents, IsoHunt. 

Your first option in automating torrent downloads is to use RSS feeds for a specific torrent creator. Once you find a well respected torrent creator you can subscribe to their RSS feed which will update every time they publish a new torrent file. Many trackers support RSS feeds and usually have the option to subscribe to a specific movie genre, or TV show. After finding a RSS feed which pertains to your interests, fire up your torrent download manager (uTorrent mac/pc, Transmission mac) and insert the RSS feed url into the options menu under Feeds. 

The simpler solution, which I find works much better and is fully automated, utilizes a system plugin (mac only) called TvShows. This preference pane takes the hassle out of finding the appropriate RSS feeds and downloads new torrent files into a designated folder. 

You can download the TvShows preference pane here http://tvshowsapp.com/

![Step 1](/assets/torrentTut/s1.png)

Once downloaded begin adding shows to your library. The application will give you the option of downloading every episode or newly released episodes in either standard definition (< 400mb) or in high definition (usually 1gb + ). 

Next, head on over to the preference panel of TvShows and make sure the destination folder for newly downloaded torrents is set to the Downloads folder. 

![Step 2](/assets/torrentTut/s2.png)

Now when TvShows finds a new episode torrent, it will automatically download the torrent from its sources and place it in the downloads folder. 

The next step is to configure your torrent manager application to continually check the Downloads folder for newly added torrent files. I like using Transmission because it’s UI is not too cluttered and it is an overall light program in terms of memory.

You can download Transmission [here](http://www.transmissionbt.com/)

![Step 3](/assets/torrentTut/s3.png)

Setting up Transmission is very easy, simply navigate to the preference window and check the box next to Auto add and make sure that the Downloads folder is selected. The last step is to enable Transmission to start downloading of torrents as soon as they are added. A few other options that I like to enable include automatically sending the torrent file to the trash once it has been added, and adding “.part” as the file extension of all uncompleted downloads. 

With this all set up TvShows will find the torrent and send it to your Downloads folder only to be automatically added to Transmission’s download queue and immediately then trashed.
